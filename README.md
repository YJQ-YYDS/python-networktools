# python-changenetwork

> 快速修改网卡信息的一个脚本集合

## 📁 文件列表

### ChangeNetworkV2.py

**功能说明**：

1. 快速禁用/启用网卡
2. 修改网卡模式（DHCP / 静态）
3. 修改网卡 IP 等信息（支持保存配置、一键加载）
4. 内置掩码计算器，一键计算掩码位并可复制

---

### 浏览器 F12 辅助脚本

- `httperrors.py`
- `export_domains.py`

---

## 🛠 使用场景

适用于需要频繁切换网络配置、调试 HTTP 错误或导出浏览器域名信息的开发与运维工作。
